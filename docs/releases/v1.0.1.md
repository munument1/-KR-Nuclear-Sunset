## Nuclear Sunset 한국어 패쳐 v1.0.1 — 한글 폰트 수정

**변경:** 기존 `NanumSquareEB.ttf`를 사용하는 tNVSE 폰트 슬롯 1, 2, 3, 6, 7, 42를 **Pretendard Bold**로 교체했습니다.

나눔스퀘어 ExtraBold는 `겍`, `걕`, `괙` 등의 CP949 확장 한글을 cmap 문자 목록에는 기록했지만 글자 윤곽선이 비어 있어 실제 게임에서 해당 글자가 보이지 않을 수 있습니다. Pretendard Bold는 해당 문자들의 실제 외곽선을 포함합니다.

- 기존 수정 `tnvse.dll` **바이너리 유지**
- 기존 원본 번역·MCM·UI·라디오·기타 폰트 **그대로 유지**
- 번역 SST·설치기 기능·프로필 동작 **변경 없음**
- 원본 v1.0.0과 새 EXE의 내장 리소스를 비교하여 폰트 XML과 카탈로그 해시 기록만 변경했는지 검증
- 실제 게임 출력은 아직 확인하지 않았으며, 폰트 변경으로 글자 폭·줄바꿈에 일부 차이가 생길 수 있습니다.

### 설치
새 ZIP의 `NuclearSunsetKoreanPatcher.exe`를 실행하여 Output을 다시 생성하고, `Output/mods/Nuclear Sunset - Korean Fonts for tNVSE`를 기존 MO2 mods 폴더에 덮어쓰세요. 한국어 폰트 모드는 기존 tNVSE 및 Default Config보다 높은 MO2 우선순위로 유지하세요. 세이브나 프로필 파일을 삭제할 필요는 없습니다.
