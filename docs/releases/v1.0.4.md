# Nuclear Sunset Korean Patcher v1.0.4 — 폴더형 배포

넥서스가 명시한 중첩 압축파일과 자체 압축 해제 실행파일의 격리 요인을 줄이기 위해 패키징을 변경합니다. 넥서스의 검사 통과를 보장하거나 기존 격리 사유를 확정한 것으로 설명하지 않습니다.

- 메인 패쳐와 XEdit 작업 프로그램을 모두 PyInstaller 폴더형(onedir)으로 빌드합니다. EXE 안에 다른 EXE와 번역 자료를 넣지 않습니다.
- 번역 데이터·XEditLib·Python 런타임을 실행파일 옆의 폴더로 제공합니다. Python 표준 라이브러리도 폴더로 풀어 배포합니다.
- 수정 tNVSE 대응 소스를 `Licenses-and-Source`의 일반 파일로 제공합니다. 소스 ZIP을 설치 ZIP 안에 중첩하지 않습니다.
- 기존 UI ESP, 번역 사전, 폰트 설정, 수정 DLL의 바이트는 v1.0.3과 동일합니다. 카탈로그에서 게임 폰트 모드에 복사하던 소스 ZIP 항목만 제거하고 소스는 배포 폴더로 옮깁니다.
- UI용 `NSKR UI Strings.esp`는 기존처럼 포함됩니다. 이번 변경은 UI ESP를 제거하는 작업이 아닙니다.

## 설치

`NuclearSunset-Korean-Patcher-v1.0.4.zip` 전체를 새 폴더에 압축 해제하고 `NuclearSunsetKoreanPatcher.exe`를 실행하세요. EXE 두 개, `_internal`, `worker-runtime`, `TranslationData`, `Backend`, `Licenses-and-Source`를 함께 유지합니다. EXE만 따로 옮기지 마세요.

Output 생성·복사·MO2 활성화 방법은 같습니다. 개발 재현용 `NuclearSunset-TranslationData-v1.0.4.zip`은 일반 설치에 필요하지 않습니다. 해당 ZIP에도 대응 소스를 일반 파일로 함께 제공합니다.

## 확인 범위

자동 검사, 폴더형 프로그램의 UTF-8 작업자 실행, 배포 ZIP을 새 폴더에 풀어 다시 실행하는 검사를 수행합니다. 번역·게임 데이터는 바꾸지 않으며 새 패키징의 실제 설치본 Output 생성도 별도로 확인합니다. 전 구간 플레이 검수 상태는 기존과 같습니다.
