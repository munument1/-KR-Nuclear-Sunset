1.0.2.0 - 2026년 7월 17일

안내:

  • 이번 버전에는 중요한 오류 수정과 업데이트, 새로운 콘텐츠 및 교체 모드가 포함되어 있습니다.

업데이트:

  • 자세한 지침은 Updating Nuclear Sunset를 참고하세요.
  • 수정되었거나 오래된 모드 목록은 지원하지 않습니다.
  • 업데이트 후 일부 모드 누락 알림은 플러그인 병합에 따른 정상적인 현상입니다.
  • 이번 업데이트에서는 xNVSE와 DXVK를 모두 수동으로 갱신해야 합니다.

xNVSE 업데이트:

  • MO2 오른쪽 패널에서 Downloads 탭을 클릭합니다.
  • 패널 아래쪽에 xnvse를 입력하고 버전 6-4-8을 찾습니다.
  • 해당 다운로드를 마우스 오른쪽 버튼으로 클릭하여 Open을 선택합니다.
  • 압축 파일에서 Data 폴더를 제외한 나머지 내용을 Stock New Vegas 폴더에 풉니다.

DXVK 업데이트:

  • 위 xNVSE와 동일한 절차를 진행하되 DXVK 3.0.1을 검색합니다.
  • 압축 파일의 모든 내용을 Stock New Vegas 폴더에 풉니다.
  • 그런 다음 MO2에서 Configure Game Settings를 다시 실행해야 합니다.

테스트:

  • 공식 Discord의 mod-testing 채널에서 Nuclear Sunset Tester - Role Requesting Thread 스레드를 통해 테스트 역할을 신청하세요.
  • 테스트에 참여하지 않거나 부실한 피드백을 제공하거나 부적절한 설치 질문을 하거나 역할을 남용하면 해당 역할이 회수됩니다.

커뮤니티:

  • NS를 즐기고 있다면 Nuclear Sunset Nexus에서 추천(Endorse)을 눌러 주세요. Nexus Collections에서 프로젝트 인지도를 높이는 데 도움이 됩니다.
  • Nuclear Sunset Nexus의 댓글이나 Reddit에 리뷰를 남겨 주세요. 여러분의 의견을 소중히 생각합니다.
  • 스크린샷을 ns-screenshots 채널에 제출하세요. 웹사이트나 로딩 화면에 소개될 수 있습니다.
  • Immersive Fast Travel이나 Immersive Sleep용 상황을 submissions에 제안해 주세요.
  • Nuclear Sunset Build Planner에서 제작한 캐릭터 빌드를 character-builds 채널에 제출하세요.

  • Nuclear Sunset 제작진 명단에 TheBooher를 추가했습니다.

  • 모든 NVR 프로필에서 Cartographer 디버그 설정을 껐습니다.
  • 여러 모드의 디버그 콘솔 출력을 제거했습니다.
