1.0.1.0 - 2026년 1월 27일

수정:

  • 진열된 물품을 구매할 때 발생하던 충돌을 수정했습니다.
  • Talon Company 암살대의 비정상적인 행동을 수정하려 시도했습니다.
  • 손전등 아이콘이 올바르게 표시되지 않던 문제를 수정했습니다.
  • NCR 교도소에서 표면이 겹쳐 깜빡이는 Z-fighting 현상을 수정했습니다.
  • TheBooher의 도움으로 파워 아머 관련 여러 문제를 수정했습니다.
  • TheBooher의 도움으로 상호작용 시 파워 피스트 애니메이션이 손상되던 문제를 수정했습니다.
  • 낮에 조준경을 사용할 때 재장전이 취소되던 문제를 수정했습니다.
  • 여성 캐릭터가 착용한 방호복의 모델 문제를 수정했습니다.
  • Wazer Rifle의 누락된 메시를 복구했습니다.
  • 일부 금속 방어구에 In Shining Armor 특전이 적용되지 않던 문제를 수정했습니다.
  • Colonel Autumn의 레이저 권총이 붉은 다이아몬드 모양의 탄환을 발사하던 문제를 수정했습니다.
  • Automatic Rifle의 사운드를 수정했습니다.
  • Outcast의 신뢰를 얻은 뒤 Protector Casdin과 대화하면 충돌하던 문제를 수정했습니다.
  • 가스 함정을 폭파할 때 충돌하던 문제를 수정했습니다.
  • Novac Hotel의 플레이어 거처에서 충돌하던 모드 요소를 수정했습니다.
  • Hell’s Hotel의 충돌 요소를 수정했습니다.
  • Colonel Autumn의 10mm 권총에 표시되는 탄약 계수기를 수정했습니다.
  • Nuclear Sunset에 적용된 무기 교체 모드에 맞춰 Lone Wanderer Theme을 패치했습니다.
  • Precision Gatling Laser의 발사체 누락을 수정했습니다.
  • TheBooher의 도움으로 은신 공격 애니메이션 누락을 수정했습니다.
  • 폭발로 적이 사지가 절단되어 사망했을 때 처치 경험치가 여러 번 지급되던 문제를 수정했습니다.
  • 호환성 관련 스켈레톤 경고가 잘못 표시되던 문제를 수정했습니다.
  • Sierra Madre 칩 봉투를 보관함에 넣을 때 충돌하던 문제를 수정했습니다.
  • 잠금장치 난이도 표시 메시지를 수정했습니다.
  • Item Cards의 카드가 지나치게 어둡게 나타나던 문제를 수정했습니다.
  • 플레이어 사망 시 자원 희소성 스크립트가 실행되어 충돌하던 문제를 수정했습니다.
  • 절벽 정렬 문제로 아래쪽에서 지형을 뚫고 볼 수 있던 현상을 수정했습니다.
  • Wordle에서 기술 수치가 너무 낮으면 과학 기술 조정이 작동하지 않던 문제를 수정했습니다.
  • Ornate Power Armor Helmet의 텍스처를 수정했습니다.
  • 일부 파워 아머 사용 시 Varmint Rifle이 막히던 문제를 수정했습니다.
  • 모터사이클 헬멧의 여러 문제를 수정했습니다.
  • Mothership Zeta에서 우주용 파워 아머를 입고 전기봉에 맞으면 충돌하던 문제를 수정했습니다.
  • Zeta Weapons Lab의 잘못된 실내 구역 포털을 수정했습니다.
  • AWOP Fiends Bunker 셀의 실내 구역 경계를 수정했습니다.
  • Infested Reservoir에서 잔해가 깜빡이던 문제를 수정했습니다.
  • Dead Money 마지막의 엘리베이터를 탄 뒤 충돌하던 문제를 수정했습니다.
  • Fairfax House에서 물체가 깜빡이던 문제를 수정했습니다.
  • 지하철 구역의 표시 거리 문제를 수정했습니다.
  • Securitron Vault에서 끝없이 이어지던 빈 공간을 막았습니다.
  • 담배에 잘못된 ySI 아이콘이 적용되던 문제를 수정했습니다.
  • Lever Action과 BlackWater 소총으로 조준할 때 모델이 겹치던 문제를 수정했습니다. 노리쇠를 조작할 때 일부 겹침은 남지만 가능한 범위에서 최선의 조정을 적용했습니다.
  • Princess가 볼트 87에 너무 일찍 진입하게 하여 Fallout 3 메인 퀘스트의 진행 순서가 꼬이던 문제를 수정했습니다.
  • Boiadero 특전의 설명이 실제 효과와 일치하지 않던 문제를 수정했습니다.
  • Weapon Wheel에서 원하는 때에 치료 아이템을 사용하지 못하던 문제를 수정했습니다.
  • Pitstop Bomb Shelter의 잘못된 실내 구역 경계를 수정했습니다.
  • Primm Sewer의 잘못된 실내 구역 경계를 수정했습니다.
  • Ulysses' Temple의 실내 구역 경계를 수정했습니다.
  • Lonesome Road 특전 메시지가 Bullet Time 대신 VATS를 가리키던 문제를 수정했습니다.
  • 정화 장치에 FEV를 주입할 때 Union Station 퀘스트가 안내되지 않던 문제를 수정했습니다.
  • Drac0pa의 도움으로 Pip-Boy 발광 매핑을 수정했습니다.

변경:

  • Outcast 밸런스 재조정 패치를 복구했습니다.
  • 레벨 상승 시 능력치 선택이 수정된 능력치가 아닌 영구 능력치를 기준으로 작동하도록 변경했습니다.
  • 목표 마커를 바라볼 때 퀘스트 이름이 표시되지 않도록 했습니다.
  • NPC가 의자에 도달할 수 있도록 차량 한 대를 비활성화했습니다.
  • 전투 경험치 관련 Stewie Tweaks 설정을 끄고 바닐라 수치를 다시 조정했습니다.
  • New Vegas Bounties의 사망한 현상금 사냥꾼 시체를 원래 위치로 되돌렸습니다.
  • 스크린샷 파일 이름을 변경했습니다.
  • 전력 질주 시 물뿐 아니라 음식과 수면 생존 수치도 소모하도록 변경했습니다.
  • View to a Kill 경험치 획득량을 하향 조정했습니다. 이제 일반 처치 경험치에 인지력을 곱한 뒤 0.1을 적용합니다.
  • Enhanced Creatures의 중복 이동 속도 강화 효과를 제거했습니다.
  • Creatures Spawn at Corpses의 강도를 줄였습니다.
  • 적의 원거리 무기 공격 거리, 특히 저격수의 사거리를 줄였습니다.
