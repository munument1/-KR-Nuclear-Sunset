중요

이 가이드는 Linux 배포판이 설치된 드라이브와 같은 드라이브에 Nuclear Sunset을 설치한다고 가정합니다.

작성 당시에는 Steam 버전 Fallout: New Vegas 설치만 설명하며 GOG 및 Epic 버전은 아직 다루지 않습니다. 해당 플랫폼 안내는 향후 추가될 예정입니다.

그래픽 환경 대신 터미널 사용을 선호하는 사용자를 위해 명령어도 함께 제공합니다. 터미널을 사용하지 않는다면 파일 탐색기에서 **숨긴 파일 표시(Show Hidden Files)**를 활성화하세요.

현재 이 구성에서는 lsfg-vk가 작동하지 않습니다.

설치 전 준비와 경로 확인​

이 가이드는 Steam 버전의 Fallout: New Vegas와 Fallout 3를 이용한 Linux 설치를 다룹니다. 기존 저장 파일이나 게임 환경을 보존하려면 삭제 및 재설치에 앞서 백업을 준비하세요.

  • 일반 Steam과 Flatpak Steam은 파일 경로가 다릅니다. 아래 두 가지 명령어가 함께 제시되면 자신의 설치 방식에 해당하는 한쪽만 실행하세요.
  • ~/NuclearSunset은 Jackify와 모드팩이 설치되는 폴더, ~/NuclearSunset/downloads는 다운로드 보관 위치입니다.
  • 나중에 생기는 [NoDelete] Stock New Vegas는 별도로 복사한 게임 설치본입니다. mods에 설치하는 TTW와는 다릅니다.
  • 터미널에서 ~는 홈 디렉터리를 의미합니다. 공백과 대괄호가 포함된 경로는 신중하게 입력하세요.
한국어판 주의

rm -rf 명령어는 파일을 영구 삭제할 수 있습니다. 먼저 실제 경로와 백업을 확인하세요. Windows의 C:\Modding 경로를 Linux에 그대로 대입하지 마세요.

  • 터미널을 열고 다음 명령어를 실행합니다.
  • mkdir ~/NuclearSunset ~/NuclearSunset/downloads
  • 홈 디렉터리에 NuclearSunset 폴더와 그 안의 downloads 폴더가 생성됩니다. 다른 드라이브에 설치한다면 해당 드라이브에서 이 폴더들을 만드세요.
  • Jackify.AppImage를 ~/NuclearSunset로 이동합니다.
한국어판 확인

최종 파일 위치가 ~/NuclearSunset/Jackify.AppImage인지 확인하세요. mkdir가 이미 존재하는 폴더를 생성하려고 하면 오류를 표시할 수 있으니, 같은 이름의 폴더가 있을 경우 기존 내용을 먼저 확인합니다.

​

  • Fallout New Vegas가 설치된 폴더로 이동해 해당 폴더의 이름을 FNVBackup과 같은 다른 이름으로 변경합니다.
    • 일반 Steam: mv ~/.local/share/Steam/steamapps/common/Fallout\ New\ Vegas/ ~/.local/share/Steam/steamapps/common/FNVBackup
    • Flatpak Steam: mv ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/common/Fallout\ New\ Vegas/ ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/common/FNVBackup
  • compatdata 폴더에서 22380을 찾아 22380-backup으로 이름을 변경합니다.
    • 일반 Steam: mv ~/.local/share/Steam/steamapps/compatdata/22380 ~/.local/share/Steam/steamapps/compatdata/22380-backup
    • Flatpak Steam: mv ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/compatdata/22380 ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/compatdata/22380-backup
한국어판 확인 — 두 개의 백업은 서로 다릅니다

FNVBackup은 기존 게임 설치 폴더를 보관한 것이고, 22380-backup은 Steam Play/Proton의 compatdata 백업입니다. 두 위치는 다르므로 각각 확인하세요. 일반 Steam과 Flatpak Steam에서 제시한 명령어를 섞어 사용하지 마세요.

  • Steam에서 Fallout New Vegas와 Fallout 3를 제거합니다.
  • Steam에서 Fallout New Vegas와 Fallout 3를 다시 설치합니다.
백업 확인

다음 단계에는 백업 폴더를 복구하는 명령어도 있으므로 기존 게임과 저장 파일이 실제로 백업되었는지 먼저 확인하세요.

​

  • Steam에서 Fallout: New Vegas를 실행합니다.
  • Detecting Video Hardware(비디오 하드웨어 감지) 메시지가 나타나면 OK를 누릅니다.
  • 런처를 닫습니다.
  • Fallout 3에서도 같은 과정을 진행합니다.

한국어판 보충 — Jackify 실행 위치

원문의 ./Jackify.AppImage 명령어는 현재 작업 디렉터리에 AppImage가 있어야 작동합니다. 실행 전에 다음 명령어로 이동하세요.

cd ~/NuclearSunset

그다음 아래의 chmod 및 AppImage 실행 명령어를 진행합니다.

  • 터미널을 열고 다음 명령어를 실행합니다.

chmod +x ~/NuclearSunset/Jackify.AppImage && ./Jackify.AppImage

  • 설정 페이지를 열고 Nexus 계정으로 로그인합니다.
  • 설정 페이지를 닫은 뒤 Modlist Tasks를 클릭하고 Install a Modlist (Automated)를 선택합니다.
  • Game Type을 Fallout: New Vegas로, Modlist를 Nuclear Sunset으로 설정합니다.
  • Install Directory에 NuclearSunset 폴더를 지정합니다.
  • Downloads Directory에서 NuclearSunset 폴더로 이동한 뒤 downloads를 선택합니다.
  • Start Installation을 누릅니다.
한국어판 확인 — Jackify의 입력값

Game Type은 Fallout: New Vegas, Modlist는 Nuclear Sunset으로 선택합니다. Install Directory에는 NuclearSunset 폴더 자체, Downloads Directory에는 그 안의 downloads를 지정합니다. 설치 프로그램이 완료되어도 뒤의 Stock New Vegas 복사와 TTW 설치를 생략해서는 안 됩니다.

경고

이 과정은 일반적으로 완료까지 최소 30분 이상 걸립니다.

​

  • 새로 설치한 New Vegas 폴더로 이동해 모든 파일을 ~/NuclearSunset/[NoDelete] \Stock \New \Vegas에 복사합니다.
    • 일반 Steam: cp -r ~/.local/share/Steam/steamapps/common/Fallout\ New\ Vegas/* ~/NuclearSunset/[NoDelete]\ Stock\ New\ Vegas/
    • Flatpak Steam: cp -r ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/common/Fallout\ New\ Vegas/* ~/NuclearSunset/[NoDelete]\ Stock\ New\ Vegas/
한국어판 확인 — 폴더가 한 단계 더 들어가지 않도록

새로 설치한 Fallout New Vegas 폴더 안의 모든 파일과 하위 폴더를 ~/NuclearSunset/[NoDelete] Stock New Vegas 안으로 복사합니다. [NoDelete] Stock New Vegas/Fallout New Vegas처럼 원래 게임 폴더가 한 단계 더 들어가는 구조는 잘못된 것입니다.

d3d9.dll과 dxvk.conf를 제거하라는 지침은 이 Stock New Vegas 복사본에 해당합니다. 원본 Steam 게임 폴더나 다른 모드팩에서 임의로 삭제하지 마세요.

중요
  • [NoDelete] Stock New Vegas에서 d3d9.dll을 반드시 제거해야 합니다. 선택 사항이 아닙니다. 이 파일은 DXVK 모드에 포함된 것이지만 Linux는 DirectX 9 게임에 DXVK를 기본적으로 사용하므로 필요하지 않습니다. 제거하지 않으면 실내에서 실외로 나갈 때마다 게임이 종료됩니다.

rm ~/NuclearSunset/[NoDelete]\ Stock\ New\ Vegas/d3d9.dll ~/NuclearSunset/[NoDelete]\ Stock\ New\ Vegas/dxvk.conf

한국어판 확인 — 백업 복구

기존 설치본을 백업해 둔 경우에만 복구 명령어를 진행하세요. 원문의 Flatpak 복구 명령은 앞에서 사용한 FNVBackup과 다른 NVBackup이라는 이름을 사용하므로, 실제로 생성된 폴더 이름을 확인하고 실행해야 합니다. 22380 삭제와 22380-backup 복구 역시 실제 경로가 일치하는지 확인하세요.

기존 게임 설치본 복구

앞에서 Fallout New Vegas를 백업했다면 기존 FNVBackup 폴더를 /path/to/Steam/steamapps/common/에 다시 둘 수 있습니다.

  • 일반 Steam
    • cp -fr ~/.local/share/Steam/steamapps/common/FNVBackup/* ~/.local/share/Steam/steamapps/common/Fallout\ New\ Vegas/
    • rm -rf ~/.local/share/Steam/steamapps/compatdata/22380 && mv ~/.local/share/Steam/steamapps/compatdata/22380-backup/ ~/.local/share/Steam/steamapps/compatdata/22380
  • Flatpak Steam
    • cp -fr ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/common/NVBackup/* ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/common/Fallout\ New\ Vegas/
    • rm -rf ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/compatdata/22380 && mv ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/compatdata/22380-backup/ ~/.var/app/com.valvesoftware.Steam/data/Steam/steamapps/compatdata/22380
한국어판 참고

rm -rf는 파일을 영구 삭제할 수 있습니다. 경로와 백업 상태를 확인한 뒤 실행하세요. 원문의 Flatpak 복구 명령에서는 앞에서 생성한 FNVBackup과 다른 NVBackup 폴더명을 사용하므로 실제 백업 폴더명을 먼저 확인해야 합니다.

한국어판 확인 — Steam에 추가할 대상

Jackify가 Steam 라이브러리 항목을 만들지 못했다면 NuclearSunset에 설치된 ModOrganizer.exe를 비 Steam 게임으로 추가합니다. 기존 바닐라 Fallout: New Vegas 항목과 혼동하지 마세요. Nuclear Sunset 항목의 Compatibility에서 원문이 지정한 Proton 11을 선택합니다.

  • Steam을 열어 게임 목록에서 Nuclear Sunset을 찾아 실행합니다.
  • Jackify가 이 항목을 자동으로 생성했어야 합니다. 없다면 왼쪽 아래 Add a Game → Add a Non-Steam Game을 선택하고 새 창의 Browse를 누릅니다. Nuclear Sunset 폴더에서 ModOrganizer.exe를 선택한 뒤 Add Selected Programs를 클릭하세요.
  • Steam 목록의 해당 항목을 마우스 오른쪽 버튼으로 클릭하여 Properties를 열고 Compatibility 탭으로 이동합니다. Force the use of a specific Steam Play compatibility tool을 활성화한 뒤 Proton 11을 선택합니다.
중요

ProtonGE나 Proton-CachyOS 같은 사용자 지정 Proton은 사용하지 마세요. Nuclear Sunset은 이러한 버전으로 실행되지 않습니다. 현재 권장 버전은 Proton 11입니다. 최신 DXVK를 사용하려면 Proton Experimental을 이용할 수 있지만 문제가 생길 가능성이 더 높습니다.

​

  • MO2 오른쪽 위의 Nuclear Sunset 드롭다운 메뉴에서 Configuring Game Settings를 선택하고 Run을 누릅니다.
  • Options에서 Ultra 프리셋을 선택합니다. 이 설정이 Nuclear Sunset의 의도된 품질입니다. 사양이 낮다면 High 또는 Medium도 고려할 수 있습니다. 이 프리셋들은 Nuclear Sunset의 모든 텍스처 해상도를 일괄적으로 낮춥니다. Low 프리셋은 사용하지 마세요. 필수 렌더링 기능이 꺼집니다.
  • Windowed가 체크되어 있으면 해제합니다.
  • OK를 누르고 런처를 종료합니다.

​

한국어판 확인 — TTW 설치 경로

Windows용 TTW Install.exe를 실행하는 방법이 아니라 Jackify의 Tools Hub → Linux Installer를 사용하는 절차입니다.

  1. TTW 자료를 압축 해제하고 .mpi 파일을 선택합니다.
  2. TTW의 출력 위치는 NuclearSunset/mods/[NoDelete] [INF] [DB] - Tale of Two Wastelands (TTW)입니다.
  3. 설치 후 YUPTTW는 별도의 [NoDelete] [INF] [DB] - YUPTTW Update 폴더에 압축을 풉니다.

TTW와 YUPTTW를 같은 폴더에 합치지 마세요.

  • Jackify에는 Tale of Two Wastelands용 설치 프로그램이 내장되어 있습니다. ModPub에서 다운로드한 설치 프로그램은 사용하지 마세요. 해당 프로그램은 오래되었고 Wine/Proton에서 잘 작동하지 않으며 Jackify보다 설치에 훨씬 많은 시간이 걸립니다. Jackify는 Fallout 3와 Fallout: New Vegas의 설치 경로도 자동으로 찾아 게임이 설치되어 있는지 확인합니다.
  • 아직 다운로드하지 않았다면 ModPub에서 Tale of Two Wastelands와 YUPTTW 파일을 받은 뒤 TTW 압축 파일을 해제합니다.
  • Jackify의 Tools Hub에서 Linux Installer를 찾습니다. 설치되어 있지 않다면 설치한 뒤 실행합니다.
  • TTW .mpi File location에서 Browse를 누르고 압축 파일을 해제한 위치로 이동해 .mpi 파일을 선택합니다.
  • Output Directory에서 Browse를 누르고 NuclearSunset/mods/로 이동해 [NoDelete] [INF] [DB] - Tale of Two Wastelands (TTW) 폴더를 선택합니다.
  • 설치를 시작하고 완료될 때까지 기다립니다.
  • 설치가 끝나면 YUPTTW 압축 파일의 내용을 ~/NuclearSunset/mods/[NoDelete] [INF] [DB] - YUPTTW Update에 풉니다.

한국어판 확인 — 4GB 패치 대상

Linux용 패처는 [NoDelete] Stock New Vegas 복사본에 적용합니다. 원본 Steam 게임 폴더에 패치를 적용하거나 Windows용 패처를 대신 실행하지 마세요.

  • 아직 다운로드하지 않았다면 Linux용 FNV 4GB 패치 압축 파일을 받아 ~/NuclearSunset/[NoDelete]\ Stock\ New\ Vegas에 풉니다.
  • FalloutNVPatcher를 마우스 오른쪽 버튼으로 클릭하고 Properties → Permissions 탭을 엽니다.
  • Execute에서 Allow executing file as program을 체크하고 OK를 누릅니다.
  • FalloutNVPatcher를 실행합니다.

터미널 사용 시 다음 명령어를 입력합니다.

cd ~/NuclearSunset/[NoDelete]\ Stock\ New\ Vegas/

chmod +x FalloutNVPatcher && ./FalloutNVPatcher

한국어판 확인 — protontricks의 선택 순서

GUI에서 Nuclear Sunset 항목 → Select the default wineprefix → Install a Windows DLL or component 순서로 선택합니다. d3dcompiler_43과 d3dcompiler_47 두 항목을 모두 체크한 뒤 설치하세요.

  • protontricks가 설치되어 있지 않다면 일반 Steam 사용자는 배포판 패키지 관리자로, Flatpak Steam 사용자는 Flatpak으로 설치합니다.
  • 터미널을 열고 protontricks --gui를 실행합니다.
  • 게임 목록에서 Nuclear Sunset을 선택합니다. 64비트 Wine 프리픽스 또는 Wine의 wow64 모드와 관련된 오류 메시지는 무시해도 됩니다.
  • Select the default wineprefix를 선택하고 OK를 누릅니다.
  • Install a Windows DLL or component를 선택합니다.
  • 아래로 스크롤하여 d3dcompiler_43과 d3dcompiler_47을 선택한 뒤 OK를 누릅니다.
  • protontricks를 닫습니다.
