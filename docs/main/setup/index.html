설치 전 확인할 사항​

게임 한국어 패치

Nuclear Sunset 설치와 영어 상태의 정상 실행 확인을 마친 뒤 한국어 패치 설치 안내를 진행하세요. 한국어 패쳐 v1.0.0 다운로드를 제공합니다. 프로필 선택 없이 설치된 기존 번역 대상 전체를 처리합니다. 가이드 사이트의 한국어 번역과 게임 한국어 패치는 별개입니다.

이 페이지는 Windows용 Nuclear Sunset 전체 설치 안내입니다. 필요한 소프트웨어를 설치한 뒤 게임을 실행하는 마지막 단계까지 위에서 아래로 진행하세요. Linux를 사용한다면 이어지는 Linux 설치 안내를 따르세요.

  • 게임 준비: 원본 가이드의 설치 요구 사항에서 지원하는 Fallout: New Vegas, Fallout 3 및 두 게임의 DLC 보유 여부를 먼저 확인하세요.
  • 계정 준비: Wabbajack에서 다운로드할 때 로그인할 Nexus Mods 계정을 준비하세요. Premium 여부에 따라 다운로드 방식이 달라집니다.
  • 기존 데이터 보존: 이미 모드를 설치했거나 저장 파일을 보관하고 있다면 게임 설치 폴더와 Documents\My Games의 관련 폴더를 별도 위치에 백업하세요.
  • 경로 예시: 본문에 나오는 C:\Modding은 예시입니다. 실제 설치 드라이브가 D라면 같은 위치를 D:\Modding으로 일관되게 바꾸세요.
  • 필수와 선택 구분: 게임을 실행하기 위해 필요한 작업과 특정 GPU 사용자·모드 제작자·컨트롤러 사용자에게만 필요한 작업을 구분했습니다. 자신의 환경에 해당하는 절차를 따르세요.
한국어판 안내 — 설치 폴더 구조 미리 보기

Nuclear Sunset은 게임 런처가 관리하는 원본 게임 폴더와 모드팩이 사용하는 독립적인 게임 복사본을 구분합니다.

C:\Modding\
├── Wabbajack\
│   └── Wabbajack Launcher.exe
└── Nuclear Sunset\
    ├── downloads\
    ├── [NoDelete] Stock New Vegas\
    └── MODS\
        ├── [NoDelete] [INF] [DB] - Tale of Two Wastelands (TTW)\
        └── [NoDelete] [INF] [DB] - YUPTTW Update\

위 구조는 작업이 완료되었을 때 주요 폴더의 위치를 설명하는 예시입니다. Wabbajack이 만들어 주는 폴더를 미리 전부 만들거나, TTW 폴더를 임의로 새로 만들라는 뜻이 아닙니다. 현재 단계에서는 아래의 '필요한 폴더 만들기'만 수행하세요.

펼치기 - Linux 설치 안내

Linux에서는 운영체제에 관한 평균 이상의 지식과 문제 해결 능력이 필요합니다. Linux 관련 도움이 필요하다면 공식 Discord의 #linux-support 채널을 이용하세요.

Linux 설치 지침은 Discord의 queenglizzyandthelizzywizzy가 친절하게 제공했습니다. Liz님, 감사합니다!

Linux 설치 안내



​

  • 드라이브의 루트 디렉터리(예: C:, D:)로 이동합니다.
  • Modding이라는 폴더를 만들고 엽니다.
  • 그 안에 Wabbajack 폴더를 만듭니다. (아직 열지 마세요.)
  • Nuclear Sunset 폴더도 만들고 엽니다.
  • Nuclear Sunset 안에 downloads 폴더를 만듭니다.
한국어판 확인 — 드라이브와 폴더 이름

예를 들어 D 드라이브를 사용한다면 D:\Modding\Wabbajack과 D:\Modding\Nuclear Sunset\downloads가 되어야 합니다. Modding\Modding처럼 폴더가 중복되거나 Nuclear Sunset\Nuclear Sunset처럼 이름이 중첩되지 않았는지 주소 표시줄에서 확인하세요. downloads는 Nuclear Sunset 폴더 안에 있어야 합니다.

다시 확인하세요

다음 경로가 실제로 존재하는지 확인하세요. 루트 드라이브 문자는 달라도 됩니다.

  • C:\Modding\Nuclear Sunset\downloads
  • C:\Modding\Wabbajack


​

이 작업을 하는 이유

이 폴더들을 백신 프로그램의 예외 항목에 추가하면 Windows 또는 타사 백신이 필수 파일을 차단하는 일을 줄일 수 있습니다.

  • Windows Security(Windows 보안)를 엽니다.
  • Virus & Threat Protection(바이러스 및 위협 방지)으로 이동합니다.
  • Virus & Threat Protection Settings(바이러스 및 위협 방지 설정)의 Manage Settings(설정 관리)를 선택합니다.
  • Exclusions(제외)까지 스크롤한 뒤 Add or Remove Exclusions(제외 추가 또는 제거)를 선택합니다.
  • 다음 폴더를 예외 항목에 추가합니다.
    • C:\Modding\Nuclear Sunset
    • C:\Modding\Wabbajack

  • 타사 백신을 사용하는 경우에도 동일한 설정을 진행합니다.
한국어판 보안 참고

백신 예외 설정은 해당 폴더에 대한 악성코드 검사를 줄이므로 보안상 위험이 커질 수 있습니다. 원본 가이드의 절차를 소개한 것이며, 신뢰할 수 없는 파일에는 적용하지 마세요. 사용 중인 보안 정책과 위험을 확인한 후 결정하세요.



​

  • Wabbajack 설치 파일을 다운로드합니다.
  • 다운로드한 파일을 C:\Modding\Wabbajack로 이동합니다.
  • Wabbajack.exe의 이름을 Wabbajack Launcher.exe로 변경합니다.
  • Wabbajack Launcher.exe를 실행해 설치를 완료합니다.
  • Wabbajack을 닫습니다.
한국어판 확인 — 파일 확장자

Windows 탐색기에서 확장명을 숨기고 있다면 이름을 바꿀 때 .exe.exe가 되지 않도록 주의하세요. 파일 탐색기의 '파일 확장명' 표시를 켜고, 최종 파일 이름이 **Wabbajack Launcher.exe**인지 확인하는 것이 안전합니다. 기존 바로 가기는 새 위치의 실행 파일을 가리키지 않을 수 있습니다.

버전 확인

기존에 설치해 둔 Wabbajack이나 이전에 만든 바로 가기를 사용하지 마세요.

Wabbajack은 반드시 Wabbajack Launcher.exe를 통해 실행해야 합니다.

독립 실행형 설치

기존의 모드 설치 환경에 영향을 주지 않는 독립적인 설치본을 만드는 첫 번째 단계입니다.

위험

깨끗한 게임 설치본을 제대로 만들지 않으면 Nuclear Sunset 설치가 실패합니다. Steam/GOG/Epic Games에서 게임을 제거하는 것만으로는 충분하지 않습니다.

  • C:\[STEAM, GOG, or EPIC FILEPATH]로 이동하여 다음 작업을 진행합니다.
    • Fallout New Vegas 폴더를 바탕 화면으로 이동합니다.
    • 백업이 필요하지 않다면 Fallout New Vegas 폴더를 삭제해도 됩니다.
    • Fallout 3 폴더를 삭제합니다.
  • C:\Users\[USERNAME]\Documents\My Games로 이동하여 다음 작업을 진행합니다.
    • FalloutNV 폴더를 바탕 화면으로 이동합니다.
    • 백업이 필요하지 않다면 FalloutNV 폴더를 삭제해도 됩니다.
    • Fallout3 폴더를 삭제합니다.
  • Steam, GOG, or Epic을 열어 다음 작업을 진행합니다.
    • Fallout: New Vegas와 Fallout 3가 여전히 설치된 것으로 표시된다면 제거합니다.
    • Fallout: New Vegas와 Fallout 3를 다시 설치합니다.
한국어판 확인 — 무엇을 백업하고 무엇을 재설치하나요?

이 단계는 이미 설치된 모드가 섞여 있지 않은 깨끗한 원본 게임 두 개를 다시 얻기 위한 절차입니다.

  1. 게임 설치 위치에 있던 Fallout New Vegas 폴더는 바탕 화면 등 안전한 위치에 보관하거나, 백업이 필요 없을 때만 삭제합니다. Fallout 3 역시 기존 설치 파일이 남아 있지 않아야 합니다.
  2. Documents\My Games\FalloutNV에는 설정과 저장 데이터가 있을 수 있으므로 게임 설치 폴더와 별개로 백업 여부를 결정하세요. Fallout3도 기존 개인 설정 파일이 남는 위치입니다.
  3. 그다음 게임 런처에서 두 게임을 다시 설치합니다. 새로 설치된 원본 게임 폴더에 기존 모드 파일을 다시 넣지 마세요. 기존 설치본 복구는 '깨끗한 Stock New Vegas 폴더 만들기' 단계에서 처리합니다.

이후 단계에서 '이동'은 원래 위치에서 파일이 사라지는 작업이고, '복사'는 원본을 유지한 채 사본을 만드는 작업입니다. 둘을 혼동하면 설치 또는 기존 게임 환경 복구에 문제가 생길 수 있습니다.

기본 설치 경로

게임 런처별 기본 경로는 다음과 같습니다.

  • Steam: C:\Program Files\Steam\steamapps\common\[Fallout: New Vegas OR Fallout 3]
  • GOG: C:\Program Files\GOG Galaxy\Games\[Fallout: New Vegas OR Fallout 3]
  • Epic: C:\Program Files\Epic Games\[Fallout: New Vegas OR Fallout 3 (please note that these folders are nested within a second Fallout folder)]

정확한 경로를 찾기 어렵다면 게임 런처에서 Fallout: New Vegas를 마우스 오른쪽 버튼으로 클릭하고 로컬 파일 위치를 여는 메뉴를 찾으세요.

노트

여기서 준비한 깨끗한 설치본과 백업은 뒤의 깨끗한 Stock New Vegas 폴더 만들기에서 사용합니다.

파일 삭제 전 확인

기존 설치 파일과 게임 설정·저장 파일을 보존하려면 먼저 별도 위치에 백업하세요. 삭제 작업은 되돌리기 어렵습니다.



​

  • Steam/GOG/Epic Games에서 Fallout: New Vegas를 실행합니다.
  • Detecting Video Hardware(비디오 하드웨어 감지) 메시지가 나타나면 OK를 선택합니다.
  • 런처를 닫습니다.
  • Fallout 3에서도 동일한 과정을 반복합니다.


​

  • Wabbajack application을 실행합니다.
  • settings 페이지를 열어 Nexus 계정으로 로그인합니다.

  • Browse Lists 페이지를 열어 Non-featured 항목을 체크하고, 검색창에 Nuclear Sunset을 입력한 뒤 Nuclear Sunset modlist 이미지를 클릭합니다.

  • Download & Install을 클릭합니다.

  • 필요한 경우 루트 드라이브 문자를 변경한 C:\Modding\Nuclear Sunset 경로를 복사(Ctrl+C)하여 Installation Location에 붙여넣습니다(Ctrl+V).
  • Download Location에는 C:\Modding\Nuclear Sunset\downloads가 자동으로 입력됩니다.
  • 확인한 후 Install을 클릭합니다.

  • 설치를 시작하고 Nexus Mods API request 창이 표시되면 승인합니다.
  • Nexus Mods Premium 구독자가 아니라면 모드마다 다운로드 버튼을 수동으로 눌러야 합니다.
한국어판 확인 — 설치 화면의 두 경로
  • Installation Location은 모드팩이 설치될 폴더입니다. C:\Modding\Nuclear Sunset 자체를 지정하며, 그 안의 downloads 폴더를 선택하지 않습니다.
  • Download Location은 받아 둔 설치 파일을 보관할 폴더입니다. C:\Modding\Nuclear Sunset\downloads를 확인하세요.
  • Nexus Premium이 없다면 다운로드 페이지로 이동해 수동 다운로드를 반복해야 합니다. 모든 다운로드와 설치가 끝날 때까지 Wabbajack을 닫거나 MO2를 먼저 실행하지 마세요.

설치가 끝났는지는 진행 막대가 멈춘 것만으로 판단하지 말고 아래에 안내된 Finished Installing Nuclear Sunset 메시지로 확인하세요.

  • 설치가 완료되면 Wabbajack 상단에 Finished Installing Nuclear Sunset 메시지가 표시됩니다.
  • Wabbajack을 닫습니다. Create Desktop Shortcut 옵션은 선택하지 마세요.
빨간색 INSTALLATION FAILED 알림

지원을 요청하기 전에 자주 묻는 질문에서 일반적인 설치 오류에 대한 초기 문제 해결 절차를 확인하세요.

주의

뒤의 단계를 시작하기 전에 설치가 완전히 종료될 때까지 기다리세요.

지시가 나오기 전에 Mod Organizer 2를 실행하지 마세요.

독립 실행형 설치

기존 모드 설치본에 영향을 주지 않는 독립적인 설치본을 만드는 두 번째 단계입니다.

1단계: 깨끗한 Stock New Vegas 폴더 생성​

  • 새로 설치한 C:\[STEAM, GOG, or EPIC FILEPATH]\Fallout New Vegas 폴더로 이동합니다. 폴더 안의 모든 파일을 복사(폴더 안에서 Ctrl+A, Ctrl+C)하여 C:\Modding\Nuclear Sunset\[NoDelete] Stock New Vegas 폴더에 붙여넣습니다(Ctrl+V).
한국어판 확인 — 폴더째 옮기는 것이 아닙니다

FalloutNV.exe 등 새로 설치한 Fallout New Vegas 폴더 안의 파일과 하위 폴더 전체를 복사합니다. [NoDelete] Stock New Vegas\Fallout New Vegas\FalloutNV.exe처럼 게임 폴더가 한 단계 더 들어간 구조가 되지 않게 하세요.

복사가 끝났다면 C:\Modding\Nuclear Sunset\[NoDelete] Stock New Vegas\FalloutNV.exe가 실제로 있는지 확인합니다. 이곳의 파일은 이후 TTW 설치, 4GB 패치, 게임 실행에 사용될 복사본입니다. 원본 게임 설치 위치와 혼동하지 마세요.

2단계: 기존 설치본과 모드 설치본의 백업 복구​

important

기존 Fallout: New Vegas 모드 설치본을 백업하지 않았다면 2단계는 건너뛰세요.

  • Clean Stock New Vegas folder를 올바르게 만든 뒤 이전에 백업한 파일들을 복구합니다.
    • 앞으로 Nuclear Sunset을 업데이트할 때 깨끗한 설치본이 다시 필요하므로, 복구 전에 이 깨끗한 폴더를 별도로 백업해 두세요.
    • 바탕 화면의 Fallout New Vegas 폴더를 원래 C:\[STEAM, GOG, or EPIC FILEPATH] 위치로 되돌리고, 메시지가 나타나면 Replace(바꾸기)를 선택합니다.
    • 바탕 화면의 FalloutNV 폴더를 원래 C:\Users\[USERNAME]\Documents\My Games 위치로 되돌리고, 메시지가 나타나면 Replace(바꾸기)를 선택합니다.
한국어판 확인 — 백업 복구 시점

이전 설치본을 되돌리는 작업은 Stock New Vegas 복사를 끝낸 다음 진행합니다. 이전에 저장한 Fallout New Vegas 폴더와 FalloutNV 폴더는 서로 다른 위치에 복구하며, 기존 폴더를 덮어쓸 때는 필요한 파일을 미리 백업했는지 다시 확인하세요. 복구한 구버전 모드 파일은 독립적인 Stock New Vegas 폴더로 복사하지 않습니다.

한국어판 확인 — 처음 실행할 때 점검
  1. MO2에서 설치 안내대로 선택한 A~L 프로필을 확인합니다.
  2. MO2 실행 항목을 **Nuclear Sunset**으로 선택했는지 확인합니다.
  3. RTSS를 사용하는 Windows 환경이라면 시스템 트레이에서 RTSS가 실행 중인지 확인합니다.
  4. Run으로 게임을 시작합니다. 게임 런처가 열리면 거기서 Play를 누르지 말고 아래 문제 해결 안내를 따르세요.
  5. 게임이 시작되었다면 일시 정지 메뉴에서 K를 눌러 단축키를 확인합니다.

프로필, 실행 항목, 게임 설치 폴더가 서로 혼동되지 않았는지를 먼저 확인하면 실행 오류를 추적하기 쉽습니다.
