# ![최소 사양 배너](https://github.com/user-attachments/assets/c9c591e2-b0f3-4123-bcbd-a9151d673476)

- **CPU:** Intel i5 2xxx / AMD FX 8xxx 이상 필수, Intel i5 6xxx / Ryzen 5 이상 권장.
- **RAM:** 16GB 이상 필수, 듀얼 채널 구성 권장.
- **GPU:** GTX 1070 8GB / R9 390 8GB 이상 필수, VRAM 8GB의 RTX 또는 RDNA 계열 권장.
- **저장 공간:** SSD 필수, NVMe SSD 권장. 여유 공간은 최소 200GB 필요합니다.

:::note
- 성능이 낮은 컴퓨터를 위한 여러 품질별 프로필은 [설치 안내](https://nuclearsunset.com/docs/main/setup#-selecting-a-nuclear-sunset-profile-)의 설명을 확인하세요.
:::
