# ![설치 요구 사항 배너](https://github.com/user-attachments/assets/75de7141-7d12-47b7-8ad1-770c0637a73d)

:::important 인내심, 컴퓨터 활용 능력, 시간이 필요합니다
Nuclear Sunset의 설치 안내는 모딩 경험과 관계없이 누구나 따라갈 수 있도록 작성되었습니다. 하지만 경험이 많아서 단계를 건너뛰어도 된다고 생각하더라도 **모든 지침을 빠짐없이 읽어야 합니다.** 사전 모딩 지식은 필요하지 않지만, 일반적인 컴퓨터 활용 능력은 갖추고 있어야 합니다.
:::

- 정식으로 구매한 *Fallout: New Vegas*, *Fallout 3* 및 두 게임의 모든 DLC.
  - Fallout: New Vegas의 영어판 Steam, Steam PCR, Steam 독일어판, GOG, Epic Games 버전은 **호환됩니다.**
    - Steam 독일어판 사용자는 [DepotDownloader](https://github.com/SteamRE/DepotDownloader)로 국제판(일반판) 실행 파일을 다운로드해야 합니다.
  - Fallout: New Vegas의 Windows Store 및 Game Pass 버전은 **호환되지 않습니다.**
  - Fallout 3는 **모든 버전이 호환됩니다.** Fallout 3의 버전과 Fallout: New Vegas의 버전은 서로 일치하지 않아도 됩니다.

:::warning 컨트롤러 지원
GOG 및 Epic Games 설치본의 기술적 제약으로 인해 [컨트롤러 지원](https://nuclearsunset.com/docs/main/controller)은 **Steam 사용자에게만** 제공됩니다.
:::

- 정식으로 라이선스가 인증된 64비트 Windows 10 이상.
- GPU용 최신 드라이버.
- [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/thank-you/net48-web-installer).
- [Visual C++ Runtime Libraries](https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/).
  - 압축을 풀고 해당 폴더를 연 뒤, `install_all.bat`을 마우스 오른쪽 버튼으로 클릭하고 `Run as administrator`(관리자 권한으로 실행)를 선택합니다.
  - 설치가 완료되면 컴퓨터를 다시 시작합니다.
- 압축 파일 도구 — [7-Zip](https://www.7-zip.org/) 권장.
- 텍스트 편집기 — [Notepad++](https://notepad-plus-plus.org/downloads/v8.7/) 권장.
- [Nexus Mods 계정](https://users.nexusmods.com/register) — Premium 구독을 **강력히 권장**합니다. 구독하지 않으면 약 1,600개의 모드를 수동으로 다운로드해야 합니다.
- [ModPub 계정](https://mod.pub/account/register).
- [Discord 계정](https://discord.com/register).
