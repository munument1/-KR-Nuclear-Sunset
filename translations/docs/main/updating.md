# ![Nuclear Sunset 업데이트 배너](https://github.com/user-attachments/assets/dfa2eb5c-89a5-4583-8b2c-c8c3166a96cb)

- 목록을 업데이트하려면 [Nuclear Sunset 설치 단계](https://nuclearsunset.com/docs/main/setup#-installing-nuclear-sunset-)의 지침에 따라 `Nuclear Sunset Wabbajack Installer`를 다시 실행합니다.
- [변경 이력](https://nuclearsunset.com/docs/changelog/1.0.0.2)에 추가 지시가 있다면 반드시 따릅니다.

- [변경 이력](https://nuclearsunset.com/docs/changelog/1.0.0.2)에 달리 명시되지 않은 한, 업데이트는 **항상 기존 저장 파일과 호환됩니다.**
- Nuclear Sunset 업데이트 시 Tale of Two Wastelands를 다시 다운로드하거나 재설치할 필요가 없습니다.
- 업데이트 후 [Mod Organizer 2(MO2) 실행](https://nuclearsunset.com/docs/main/setup#-launching-mod-organizer-2-mo2-)과 [게임 설정 구성](https://nuclearsunset.com/docs/main/setup#-configuring-game-settings-) 단계 일부를 다시 설정하라는 안내가 표시될 수 있습니다.
- 업데이트 후 모드 누락 알림이 표시되는 것은 정상일 수 있으며, 플러그인 병합을 반영한 결과입니다.
- 사용자가 모드 목록에 직접 적용한 수정 사항은 업데이트 시 **초기화됩니다.**

:::danger 변경 이력을 확인하세요
[변경 이력](https://nuclearsunset.com/docs/changelog/1.0.0.2)에는 업데이트 안내, 추가·제거 사항, 버그 수정, 그리고 특히 중요한 **업데이트 시 필요한 수동 작업**이 포함되어 있습니다.
:::
