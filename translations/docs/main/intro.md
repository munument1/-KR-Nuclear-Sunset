# ![뉴클리어 선셋 제목 배너](https://github.com/user-attachments/assets/9f6ccafa-b028-4b1e-840f-ff5ef99cfc87)

**Nuclear Sunset(NS)**은 Fallout: New Vegas와 Fallout 3를 전면 개편하는 모드 목록입니다. 1,500개가 넘는 모드를 이용해 두 황무지의 모든 측면을 현대화하고, 확장하며, 균형을 조정하고, 개선합니다.

<br></br>

**생존을 중심으로 설계된 궁극의 하드코어 TTW 경험**을 원하는 방식으로 즐길 수 있도록 다양한 모드를 제공합니다.

- 정통 하드코어 경험을 원한다면? 준비되어 있습니다.
- 조금 완화된 하드코어 경험을 원한다면? Softercore를 시도해 보세요.
- 더 어려운 경험을 원한다면? Hardercore에 도전해 보세요.

<br></br>

:::important Nuclear Sunset만의 차별점은 무엇인가요?
- 두 황무지에 세심하게 검토하고 통합한 다양한 추가 콘텐츠와 확장 요소가 있습니다.
- 독자적인 SALVO 처리 방식과 자산 최적화로 이만한 규모의 모드 목록에서도 뛰어난 안정성과 성능을 제공합니다.
- 무기 소리, 배경 음악, 음성 대사에 이르기까지 새로운 사운드와 맞춤형 사운드가 풍부합니다.
- 수많은 지형과 월드스페이스 개편을 두 황무지에 정교하게 통합했습니다.
- 게임 플레이와 몰입도를 높이는 수십 가지 신규 기능과 시스템을 제공합니다.
:::
