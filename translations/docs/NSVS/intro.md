# New Vegas와 TTW를 위한 현대적인 시각 효과.

Nuclear Sunset이 처음이라면, 이 프로젝트는 Fallout 두 작품을 완전히 새로운 경험으로 바꾸는 하드코어 TTW용 Wabbajack 모드 목록입니다. 모드 목록 자체가 궁금하다면 [소개 페이지](https://nuclearsunset.com/docs/main/intro)를 살펴보세요.

간단히 말해 Nuclear Sunset에 적용한 독자적인 작업 과정에서 게임 플레이 관련 변경 사항을 제외하고, 모드 목록을 대표하는 시각적 개선 요소만 남긴 버전입니다. 덕분에 전체 Nuclear Sunset 모드 목록을 설치하지 않고도 시각 효과를 이용할 수 있습니다.

텍스처 교체, 새로운 텍스처와 모델, 기존 모델 개선, 조명, 무기, 방어구 등 다양한 요소를 포함합니다. 뛰어난 미관과 성능을 위해 전체 요소를 일관되고 정교하게 구성했습니다.
