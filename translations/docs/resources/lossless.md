# ![Lossless Scaling Guide](https://github.com/user-attachments/assets/f45d9afb-92b4-4474-bed1-51adc63a62dd)

:::danger 선택 사항인 유료 프로그램
- Lossless Scaling은 Nuclear Sunset이나 모드가 적용된 Fallout: New Vegas 실행에 **필수는 아닙니다.** 하지만 FPS를 크게 높여, 경우에 따라 성능을 두 배 또는 세 배로 높일 수도 있는 강력한 도구입니다.
- Lossless Scaling의 원문 안내 가격은 미화 7달러입니다. 실제 현재 가격은 구매 페이지에서 확인하세요.
- Lossless Scaling은 `AMD Fluid Motion Frames` 등 다른 프레임 생성 기술과 함께 사용하지 마세요.
- Nuclear Sunset 팀은 Lossless Scaling과 제휴하거나 금전적 이해관계를 맺고 있지 않습니다.
:::

:::warning 공식 지원 대상 아님
Nuclear Sunset 팀은 Lossless Scaling 프로그램에 관한 기술 지원을 제공하지 않습니다.
:::

- **[Lossless Scaling](https://store.steampowered.com/app/993090/Lossless_Scaling/)**을 구매·다운로드·설치한 뒤 실행합니다.
설정을 다음 스크린샷과 동일하게 구성합니다.

   ![LS](https://github.com/user-attachments/assets/1817e1e3-b3f4-4df5-802c-636405ffb377)

- Lossless Scaling을 실행한 상태에서 Nuclear Sunset 또는 Fallout: New Vegas를 실행합니다. 게임 안에서 `Ctrl + Alt + S`를 누르면 스케일링이 시작됩니다.
