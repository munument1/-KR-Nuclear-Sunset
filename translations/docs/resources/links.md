# <p align="center"> ![General Resources](https://github.com/user-attachments/assets/7f943e7b-b9a8-4e7c-a1ec-ddbf5317d2a9) </p>

- **[Basics of xEdit](https://moddinglinked.com/xedit.html)**
  - xEdit의 사용 목적과 기능을 설명하는 입문 가이드입니다.
- **[The Method](https://moddinglinked.com/themethod.html)**
  - 모드 목록을 구성할 때 충돌을 해결하는 방법을 단계별로 안내합니다.
- **[Tools to Avoid](https://vivanewvegas.moddinglinked.com/avoid-tools.html)**
  - 안정성을 위해 사용하지 않는 편이 좋은 모딩 도구를 정리한 목록입니다(모든 도구를 망라한 목록은 아닙니다).
- **[Mods to Avoid](https://vivanewvegas.moddinglinked.com/avoid-mods.html)**
  - 안정성을 위해 피하는 편이 좋은 모드를 정리한 목록입니다(모든 모드를 망라한 목록은 아닙니다).

# <p align="center"> ![Fallout Resources](https://github.com/user-attachments/assets/8eb848cb-8b44-4a82-b7fe-2525c96f22c4) </p>

- **[GECK Wiki](https://geckwiki.com/index.php/Main_Page)**
  - GECK 사용, 스크립트 제작, 상세 게임 시스템을 다루는 Bethesda GECK Wiki의 커뮤니티 운영 후속 위키입니다.
- **[Independent Fallout Wiki](https://fallout.wiki/wiki/Fallout_Wiki)**
  - Fallout 게임, 커뮤니티, 모드를 폭넓게 다루는 팬 제작 백과사전입니다.
- **[LOD Guide](https://vivanewvegas.moddinglinked.com/lod.html)**
  - xLODGen 사용법을 비롯해 원거리 디테일(LOD) 생성 및 사용 방법을 설명합니다.
- **[Decompression Guide](https://vivanewvegas.moddinglinked.com/decompress.html)**
  - 성능 개선과 화면 끊김 감소를 위해 로드 순서에 포함된 플러그인의 압축을 해제하는 방법을 안내합니다.
- **[New Vegas Reloaded (NVR) Wiki](https://dlpnd.github.io/nvr-wiki/)**
  - New Vegas Reloaded의 모든 주요 기능을 자세히 설명하는 위키입니다.
