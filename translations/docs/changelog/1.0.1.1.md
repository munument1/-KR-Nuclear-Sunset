# <p align="center"> 1.0.1.1 - 2026년 2월 4일 </p>

**수정:**
- View to Kill의 성능을 실제로 하향 조정했습니다.
- 1인칭 시점에서 파워 아머 팔이 표시되지 않던 문제를 수정했습니다.
- Booher의 도움으로 3인칭 전기톱 공격 애니메이션을 수정했습니다.
- Booher의 도움으로 산탄총 애니메이션을 수정했습니다.
- 전투 중이 아닌데도 전력 질주 시 AP가 소모되던 문제를 수정했습니다.
- 제타의 드론이 보이지 않던 문제를 수정했습니다.
- Forged Receiver 모드 사용 시 Brush Gun의 메시가 누락되던 문제를 수정했습니다.
- 방한형 전투 헬멧을 착용하면 머리가 보이지 않던 문제를 수정했습니다.
- 다른 잡지는 +5를 제공하는데 Milsurp Review만 +10을 제공하던 문제를 수정했습니다.
- Talon Company 암살대 대장이 플레이어를 적대하지 않던 문제를 수정했습니다.
