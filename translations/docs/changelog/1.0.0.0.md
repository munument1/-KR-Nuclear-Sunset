- 자세한 지침은 [Updating Nuclear Sunset](<https://nuclearsunset.com/docs/main/updating>)를 참고하세요.

**수정:**
- Medkit 분해 제작법에 기술 요구치가 1000으로 설정된 문제를 수정했습니다.
- 손도끼와 투척 손도끼를 상호 제작하며 경험치를 반복 획득할 수 있던 문제를 수정했습니다.
- K9000 및 FIDO로 조준 사격(ADS)할 때 충돌하던 문제를 수정했습니다.
- 적용 가능한 장비를 표시하는 특전의 목록이 간혹 비어 있던 문제를 수정했습니다.
- 해당 특전의 장비 목록에 같은 항목만 반복 표시되던 문제를 수정했습니다.
- Congenital Heart Defect와 Paranoid 안내 메시지가 나타나지 않던 문제를 수정했습니다.
- 일반 해킹에 성공한 뒤 터미널에 접속하거나 Wordle 해킹에 성공해도 감전되던 문제를 수정했습니다.
- Humbled 상태에서 Big Guns와 Energy Weapons 기술이 감소하지 않던 문제를 수정했습니다.
- 무기 개조 설명을 수정했습니다.
- Van Graff Salvaged Power Armor가 적절한 FormList에 포함되지 않던 문제를 수정했습니다.
- Arctic Riot Armor와 Helmet의 설명을 수정했습니다.
- Sierra Madre Suite의 창문 메시가 누락되던 문제를 수정했습니다.
- DLC 스노우글로브가 캡 500개 대신 2000개를 지급하던 문제를 수정했습니다.
- DLC 스노우글로브가 The Sink 전시대에 놓이지 않던 문제를 수정했습니다.
- 여성 캐릭터의 Pimp-Boy를 수정했습니다.
- 남성 캐릭터의 Pip-Boy와 Pimp-Boy에서 사각형 버튼 발광 효과를 수정했습니다.
- Timed Saves 때문에 발생할 가능성이 있는 충돌을 수정하려 시도했습니다.
- Dogmeat 메시지 창에서 문구 끝부분이 잘리던 문제를 수정했습니다.
- .45 Harness 제작 및 분해를 반복해 경험치를 획득할 수 있던 문제를 수정했습니다.
- Sarah Weintraub가 받아야 할 모든 볼트 슈트를 수령하지 않던 문제를 수정했습니다.
- Autumn Leaves의 메시지에서 VATS라고 적힌 부분을 Bullet Time으로 수정했습니다.
- 도박이 금지되었거나 칩이 없을 때 도박을 시도하면 행운 능력치가 변하던 문제를 수정했습니다.
- Searchlight의 구울 출현 목록에 야생 구울 어린이가 포함된 문제를 수정했습니다.
- 보관함에서 탄약이 비정상적으로 많이 생성될 수 있던 문제를 수정했습니다.
- 사용하지 않는 탄약 종류가 보관함에 추가되던 문제를 수정했습니다.
