# <p align="center"> 1.0.0.1 - 2025년 12월 19일 </p>

**안내:**
- 이번 핫픽스에는 여러 모드 업데이트, 일부 프로필 변경 사항, 정상적인 플레이를 위한 중요한 수정이 포함되어 있습니다.
<br></br>

**업데이트:**
- 자세한 지침은 [Updating Nuclear Sunset](<https://nuclearsunset.com/docs/main/updating>)를 참고하세요.
- 임의로 변경했거나 오래된 모드 목록은 지원하지 않습니다.
- 업데이트 후 일부 모드 누락 알림은 플러그인 병합에 따른 정상적인 현상입니다.
<br></br>

**테스트:**
- 공식 Discord [mod-testing](https://discord.com/channels/1445447774035251323/1445462359681532155) 채널의 `Nuclear Sunset Tester - Role Requesting Thread` 스레드에서 테스트 역할을 요청하세요.
- 테스트에 참여하지 않거나 부실한 피드백을 제공하거나 부적절한 설치 질문을 하거나 역할을 남용하면 테스트 역할이 회수됩니다.
<br></br>

 **커뮤니티:**
- NS를 즐기고 있다면 [Nuclear Sunset Nexus](<https://www.nexusmods.com/newvegas/mods/94967>)에서 추천(Endorse)을 눌러 주세요. Nexus Collections에서 프로젝트가 더 잘 알려지는 데 도움이 됩니다.
- [Nuclear Sunset Nexus](<https://www.nexusmods.com/newvegas/mods/94967?tab=posts>)의 댓글이나 Reddit에 리뷰를 남겨 주세요. 여러분의 의견을 소중히 생각합니다!
- Nuclear Sunset 스크린샷을 [ns-screenshots](https://discord.com/channels/1445447774035251323/1445472863455805684) 채널에 제출하세요. 웹사이트 또는 로딩 화면에 소개될 수 있습니다!
- Immersive Fast Travel 또는 Immersive Sleep용 상황을 [submissions](https://discord.com/channels/1445447774035251323/1445462646424993976) 채널에 제안해 주세요!
- [Nuclear Sunset Build Planner](https://mrgassy.github.io/Gassy-s-Nuclear-Sunset-Build-Planner/)로 캐릭터 빌드를 제작하여 [character-builds](https://discord.com/channels/1445447774035251323/1445462178172895262) 채널에 제출하세요!
<br></br>

**수정:**
- 스크립트가 콘솔에 과도한 출력을 발생시켜 FPS가 낮아지던 문제를 수정했습니다.
- 21:9 MAPMO 프리셋을 수정했습니다.
- Forced Entry와 Dynamic Interaction Prompts 간 충돌을 수정했습니다.
- 새로 설치한 환경의 기본 단축키를 수정했습니다.
- Tweaks 메뉴를 열 때 나타나는 경고문에서 Nuclear Sunset 이름을 잘못 표기한 문제를 수정했습니다.
- 목록 업데이트 후 Dialogue History가 유지되지 않던 문제를 수정했습니다.
- Zion Trail Redux의 누락된 나무 자산을 복구했습니다.
- 튜토리얼 메시지에 NuclearSunset.com 대신 NuclearSunset.net이 나타나던 문제를 수정했습니다.
<br></br>


**변경:**
- Aim Collision Indicator가 조준 중에만 나타나도록 변경했습니다.
- Map Marker Added 알림 팝업을 활성화했습니다.
- 사용자가 변경할 필요 없는 기능의 단축키를 Keybinder MCM에서 다수 제거했습니다.
<br></br>


**제거:**
- Whiteout 2.0 NVR을 제거했습니다.
- New Vegas Unloaded를 제거했습니다.
<br></br>


**추가:**
- Hikikomori Remake - Legacy Filter Version을 추가하고 이를 위한 MO2 프로필을 새로 만들었습니다.
- Rebar Club and Nuka Breaker Ratified를 추가했습니다.
<br></br>
