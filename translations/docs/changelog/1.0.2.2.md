# <p align="center"> 1.0.2.2 - 2026년 9월 4일 </p>

**안내:**
- 이번 핫픽스는 주로 1.0.2.1에서 보고된 여러 오류를 수정합니다.
<br></br>

**업데이트:**
- 자세한 절차는 [Updating Nuclear Sunset](<https://nuclearsunset.com/docs/main/updating>)를 참고하세요.
- 임의로 수정했거나 오래된 모드 목록은 지원하지 않습니다.
- 업데이트 후 일부 모드가 누락되었다는 알림은 플러그인 병합에 따른 정상적인 현상입니다.
- 네. 이번 업데이트는 기존 저장 파일과 호환됩니다.
<br></br>

**테스트:**
- 공식 Discord의 [mod-testing](https://discord.com/channels/1445447774035251323/1445462359681532155) 채널에서 `Nuclear Sunset Tester - Role Requesting Thread` 스레드를 통해 테스트 역할을 신청하세요.
- 테스트에 참여하지 않거나 부실한 피드백을 제공하거나 부적절한 설치 질문을 하거나 역할을 남용하면 해당 역할이 회수됩니다.
<br></br>

 **커뮤니티:**
- NS를 즐기고 있다면 [Nuclear Sunset Nexus](<https://www.nexusmods.com/newvegas/mods/94967>) 및 [Collection](https://www.nexusmods.com/games/newvegas/collections/qnlxwm)에서 추천(Endorse)을 눌러 주세요.
- 댓글이나 Reddit에 리뷰를 남겨 주세요. 여러분의 의견을 소중히 생각합니다!
- 스크린샷을 [ns-screenshots](https://discord.com/channels/1445447774035251323/1445472863455805684) 채널에 제출하면 웹사이트나 로딩 화면에 소개될 수 있습니다.
- Immersive Fast Travel 또는 Immersive Sleep용 상황을 [submissions](https://discord.com/channels/1445447774035251323/1445462646424993976) 채널에 제안해 주세요.
- [Nuclear Sunset Build Planner](<https://mrgassy.github.io/Gassy-s-Nuclear-Sunset-Build-Planner/>)로 제작한 캐릭터 빌드를 [character-builds](https://discord.com/channels/1445447774035251323/1445462178172895262) 채널에 제출하세요.

**수정:**
- 맨손 무기 사용 시 손이 표시되지 않던 문제를 수정했습니다.
- Sealed Sewers로 이어지는 문이 누락된 문제를 수정했습니다.
- 볼더 시티의 계단 모서리 벽 누락을 수정했습니다.
- AwopSearchlightBombShelter의 탁자가 보이지 않던 문제를 수정했습니다.
- AWOPNovacSewerEast의 실내 구역 포털 누락을 수정했습니다.
- Reilly’s Rangers Outpost의 잘못된 실내 구역 경계를 수정했습니다.
- 볼트 21의 손상된 실내 구역 포털을 수정했습니다.
- RepconHQ01의 잘못된 실내 구역 경계를 수정했습니다.
- Lived-In AIO의 차량이 Mojave Scenery Overhaul의 고정 배치 물체와 겹치던 문제를 수정했습니다.
- 넬리스 공군기지에 나무, 바위, 덤불이 공중에 떠 있던 문제를 수정했습니다.
- 프리사이드 통로 문 누락을 수정하고 Cerulean Robotics의 두 번째 출입구를 제거했습니다.
- AWCapitolResearchUpper의 실내 구역 경계를 전면 재작업했습니다.
- C4 기폭장치 애니메이션을 수정했습니다.
- Wasteland Survival Guide 퀘스트 완료 전에 WSG 책이 등장하던 문제를 수정했습니다.
- Keybinder MCM에서 Missing Mod-Added Keybinds 1 페이지가 누락된 문제를 수정했습니다.
- ScriptRunner 오류로 여러 무기에서 잘못된 소리가 재생되던 문제를 수정했습니다.
- Dry Sewer(OurLadyHope04)의 잘못된 실내 구역 경계를 조정했습니다.
- 보조키를 누른 상태로 저장하면 단축키가 꼬이던 문제를 수정했습니다.
- Bullet Time이 피격 순간 정지 효과(Hitstop)를 방해하던 문제를 수정했습니다.
- Dogmeat으로 빠른 이동할 때 캡이 잘못 차감되던 문제를 수정했습니다.
- 긴 총열 개조를 장착한 5.56 Rifle의 기계식 조준기 정렬을 수정했습니다.
