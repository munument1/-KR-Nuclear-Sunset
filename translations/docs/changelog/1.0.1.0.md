# <p align="center"> 1.0.1.0 - 2026년 1월 27일 </p>

**수정:**
- 진열된 물품을 구매할 때 발생하던 충돌을 수정했습니다.
- Talon Company 암살대의 비정상적인 행동을 수정하려 시도했습니다.
- 손전등 아이콘이 올바르게 표시되지 않던 문제를 수정했습니다.
- NCR 교도소에서 표면이 겹쳐 깜빡이는 Z-fighting 현상을 수정했습니다.
- TheBooher의 도움으로 파워 아머 관련 여러 문제를 수정했습니다.
- TheBooher의 도움으로 상호작용 시 파워 피스트 애니메이션이 손상되던 문제를 수정했습니다.
- 낮에 조준경을 사용할 때 재장전이 취소되던 문제를 수정했습니다.
- 여성 캐릭터가 착용한 방호복의 모델 문제를 수정했습니다.
- Wazer Rifle의 누락된 메시를 복구했습니다.
- 일부 금속 방어구에 In Shining Armor 특전이 적용되지 않던 문제를 수정했습니다.
- Colonel Autumn의 레이저 권총이 붉은 다이아몬드 모양의 탄환을 발사하던 문제를 수정했습니다.
- Automatic Rifle의 사운드를 수정했습니다.
- Outcast의 신뢰를 얻은 뒤 Protector Casdin과 대화하면 충돌하던 문제를 수정했습니다.

- Novac Hotel의 플레이어 거처에서 충돌하던 모드 요소를 수정했습니다.
- Hell’s Hotel의 충돌 요소를 수정했습니다.
- Colonel Autumn의 10mm 권총에 표시되는 탄약 계수기를 수정했습니다.

- 폭발로 적이 사지가 절단되어 사망했을 때 처치 경험치가 여러 번 지급되던 문제를 수정했습니다.

**변경:**
- Outcast 밸런스 재조정 패치를 복구했습니다.
- 레벨 상승 시 능력치 선택이 수정된 능력치가 아닌 영구 능력치를 기준으로 작동하도록 변경했습니다.
- 목표 마커를 바라볼 때 퀘스트 이름이 표시되지 않도록 했습니다.
- NPC가 의자에 도달할 수 있도록 차량 한 대를 비활성화했습니다.
- 전투 경험치 관련 Stewie Tweaks 설정을 끄고 바닐라 수치를 다시 조정했습니다.
- New Vegas Bounties의 사망한 현상금 사냥꾼 시체를 원래 위치로 되돌렸습니다.
- 스크린샷 파일 이름을 변경했습니다.
- 전력 질주 시 물뿐 아니라 음식과 수면 생존 수치도 소모하도록 변경했습니다.
- View to a Kill 경험치 획득량을 하향 조정했습니다. 이제 일반 처치 경험치에 인지력을 곱한 뒤 0.1을 적용합니다.
- Enhanced Creatures의 중복 이동 속도 강화 효과를 제거했습니다.
- Creatures Spawn at Corpses의 강도를 줄였습니다.
- 적의 원거리 무기 공격 거리, 특히 저격수의 사거리를 줄였습니다.
