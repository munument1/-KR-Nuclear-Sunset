# <p align="center"> 1.0.2.0 - 2026년 7월 17일 </p>

**안내:**
- 이번 버전에는 중요한 오류 수정과 업데이트, 새로운 콘텐츠 및 교체 모드가 포함되어 있습니다.
<br></br>

**업데이트:**
- 자세한 지침은 [Updating Nuclear Sunset](<https://nuclearsunset.com/docs/main/updating>)를 참고하세요.
- 수정되었거나 오래된 모드 목록은 지원하지 않습니다.
- 업데이트 후 일부 모드 누락 알림은 플러그인 병합에 따른 정상적인 현상입니다.
- 이번 업데이트에서는 xNVSE와 DXVK를 모두 수동으로 갱신해야 합니다.
<br></br>

**xNVSE 업데이트:**
- MO2 오른쪽 패널에서 `Downloads` 탭을 클릭합니다.
- 패널 아래쪽에 `xnvse`를 입력하고 버전 `6-4-8`을 찾습니다.
- 해당 다운로드를 마우스 오른쪽 버튼으로 클릭하여 `Open`을 선택합니다.
- 압축 파일에서 **Data 폴더를 제외한** 나머지 내용을 `Stock New Vegas` 폴더에 풉니다.
<br></br>

**DXVK 업데이트:**
- 위 xNVSE와 동일한 절차를 진행하되 `DXVK 3.0.1`을 검색합니다.
- 압축 파일의 모든 내용을 `Stock New Vegas` 폴더에 풉니다.
- 그런 다음 MO2에서 `Configure Game Settings`를 다시 실행해야 합니다.
<br></br>

**테스트:**
- 공식 Discord의 [mod-testing](https://discord.com/channels/1445447774035251323/1445462359681532155) 채널에서 `Nuclear Sunset Tester - Role Requesting Thread` 스레드를 통해 테스트 역할을 신청하세요.

**변경:**
- Nuclear Sunset 제작진 명단에 TheBooher를 추가했습니다.
- 정화 장치를 작동시킨 뒤 플레이어가 반드시 살아남아야 한다는 조건을 제거했습니다. 이제 항상 생존합니다.
- Fast Travel Expenses에서 마우스를 올렸을 때 비용을 표시하는 기능을 꺼 충돌 가능성을 줄였습니다.
- 이제 플레이어는 근접 무기를 휘두르는 것만으로 사망하지 않습니다.
- 근접 무기의 강공격으로 소모되는 생존 수치를 줄였습니다.
- Ammo Press의 용량을 늘렸습니다.
- 나침반에 NPC 표시점을 나타내도록 했습니다.
- Stewie Tweaks의 `bPickpocketFleeingActors`, `bVanityCamReturnsToFirstPerson`, `bPickpocketCaughtCausesDetection`을 활성화했습니다.
- Stewie Tweaks의 `bReloadingPreventsWeaponHotkeys`를 비활성화했습니다.
- 모든 NVR 프로필에서 Cartographer 디버그 설정을 껐습니다.
- 여러 모드의 디버그 콘솔 출력을 제거했습니다.
- 반복 제작으로 경험치를 악용할 수 있는 Cosmic Knife Gauntlet 제작 및 분해 레시피를 차단했습니다.
- 무기를 뽑은 채 전력 질주할 때 적용되던 무기 힘 요구 조건을 제거했습니다.
