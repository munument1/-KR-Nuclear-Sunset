# Nuclear Sunset Korean Patcher v1.0.7

퍽 설명·요구 조건의 한글 깨짐과 실행 중 다시 나타나는 영어 문구를 수정했습니다. 아이템 사용 알림과 중화기 설명도 함께 보완했습니다.

- 퍽 설명, 요구 조건, 기술·능력치 이름을 조합할 때의 인코딩 혼용 수정.
- 혈액 팩·태그!를 포함한 동적 퍽 설명, 관통 타격·생명력 부여·수학 천재·신속한 주머니 등의 추가 설명 번역.
- 의료품·물 담기·잡지 능력치·외상 경험치 알림, 왕진 가방·부목 메뉴 및 워들 해킹 설명 보완.
- JIP가 영어로 덮어쓰는 중화기 설명을 한국어로 교체하도록 tNVSE 설정 복구. 지원 대상은 JIP LN NVSE 57.30입니다.
- ShowOff/UI Organizer의 내부 조회 이름을 번역해 설치 버전이 `-1`로 표시되던 오류 수정. 버전 검사와 경고는 유지하며 내부 식별자를 번역하지 않도록 보호합니다.
- 이슈 #13의 결점 선택창, Educated 런타임 설명, NPC·잡동사니 이름 및 레벨업 능력치 선택창 수정 포함.

## 업데이트 방법

**전체 패쳐 ZIP을 새 폴더에 풀고 새 Output을 생성해야 합니다.** EXE 한 개나 TranslationData만 교체하면 이번 프로그램 수정이 적용되지 않습니다. 덮어쓸 모드 파일을 백업한 후 `Output/mods` 안의 폴더들을 실제 MO2 `mods`에 병합하세요. 기존 Output을 재사용하지 마세요.

게임을 완전히 종료한 상태에서 적용하고 다시 실행하세요. 저장 파일만 다시 불러오면 기존 스크립트가 메모리에 남을 수 있습니다. 게임 및 Nuclear Sunset 원본 모드는 별도 설치가 필요합니다. 패쳐는 설치 폴더를 직접 변경하지 않고 Output만 생성합니다.

## 확인 범위

사용자가 실제 게임에서 퍽 표시와 ShowOff 경고 복구를 확인했습니다. 모든 퀘스트·아이템·선택지를 실제 플레이로 확인한 것은 아닙니다. 설치된 모드 버전이나 원문이 달라 검증할 수 없는 항목은 보고서에 남기고 보존합니다. 기존 세이브에 저장된 NPC 이름은 즉시 갱신되지 않을 수 있습니다.

xNVSE와 다른 NVSE 플러그인은 모드리스트 요구 사항에 맞게 별도로 설치하세요. 이번 패쳐 배포물에 xNVSE 본체는 추가하지 않습니다.
