# v1.0.5 업데이트 안내

- **기존 한국어 패치 설치자의 JSON/INI 업데이트 문제를 수정했습니다.** 이미 번역된 문구는 정상 처리하고, 카탈로그에 기록된 과거 번역 문자열은 최신 문구로 갱신합니다. 출처가 불분명한 사용자 지정 문자열은 덮어쓰지 않습니다.
- 기존 한국어 패치가 입력 모드에 남아 있어도 같은 레코드·필드·경로의 최신 한국어 번역을 재사용합니다.
- 기존 버전의 `TranslationData`를 가진 배포 담당자는 `tools/merge_previous_catalogs.py`로 과거 번역 문자열을 새 카탈로그에 포함할 수 있습니다. 이렇게 연결된 이전 번역은 새 문구로 갱신됩니다. 이력이 없다면 추측해서 이전 한글을 변경하지 않고 대응 실패 내역에 남깁니다.
- `PERK`를 포함한 플러그인 매핑에서 새 영문 원문이 기존 카탈로그와 달라지면 해당 레코드/필드 경로를 확인할 수 있도록 대응 실패 원인을 분류합니다.
- 별도 Output과 결과 보고서의 출력을 유지합니다. GUI는 동일한 이름의 출력물이 이미 있으면 고유 이름으로 새 폴더를 만듭니다.
- Nuclear Sunset #11의 NVSE 런타임 설명문을 처리합니다. `Tag Perk Description Adjustment`, `SSS - Sweets Simple Settings`의 `gr_TagPerkDescriptionSetter.txt` 영어 설명을 한국어로 바꿉니다. `Bullet Time - Perk Consistency Patch`는 ASCII 영어 설명에 한해서만 정규식 변환을 적용합니다. 영어로 유지한 `Concentrated Fire`(FormID `044CAF`)도 원래의 `V.A.T.S.` → `Bullet Time` 치환을 유지합니다.
- **집중 사격(Concentrated Fire)의 퍽 효과 설명만 영어로 유지합니다.** 해당 설명은 JIP/Bullet Time 런타임 처리 중 한국어가 `??`로 깨진 사례가 있어 `FalloutNV.esm`과 `S6S Base Game Perks Redux.esp`의 해당 PERK/DESC에 한해 영어 원문을 적용합니다. 퍽 이름과 다른 퍽의 번역은 유지하고, 이미 설치된 한국어 설명도 확인된 원문·이전 번역이 일치할 때 영어로 갱신합니다. 인코딩의 정확한 손상 위치는 아직 특정되지 않았습니다.
- `NS.esp`의 Head Hunter, `Sweet Consumables.esp`의 Fast Metabolism은 **기존 플러그인의 번역 출력본 안의 컴파일된 스크립트 문자열**을 직접 교체합니다. SCPT의 원본 영어 상수·길이·스크립트 헤더·레코드 구조를 검증하고 SCTX/SCDA 및 필요한 크기 정보만 갱신합니다. 새로운 ESP, tNVSE 번역 사전 모드, 혼합 문자 사전 설정은 추가하지 않습니다.

## #11 특전 번역 검수 현황

실제 설치된 테스트 Output의 PERK 번역이 한국어로 들어간 사실을 확인했으며, 게임 시작 시 NVSE·컴파일된 SCPT 스크립트가 다시 바꾸는 원인을 분리했습니다. 기존 플러그인 파일은 번역 후 별도 Output으로 생성하며, 그 안에서 해당 컴파일된 문자열 상수 및 구조적 크기 필드를 함께 교체합니다. SCTX만 바꿔 놓고 SCDA 실행 코드는 영어로 남겨 두지 않습니다. JIP NVSE의 Script Runner와 컴파일된 한국어 설명의 실제 게임 표시는 **인게임 검증이 필요**합니다.

## 검증

`python -m unittest discover -s tests`로 소스 단계 회귀 검사. 새 배포본의 게임 실행 검증과 이전 버전 카탈로그의 실제 대응 검사는 배포 전 필요합니다.
