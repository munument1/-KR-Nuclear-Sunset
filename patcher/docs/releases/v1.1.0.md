# Nuclear Sunset Korean Patcher v1.1.0

## 세이브/불러오기 한글 레벨 칭호 수정 (#27)

세이브 파일의 UTF-8 칭호와 CP949 UI 텍스트가 결합될 때 글자가 깨지는 문제를 `TileText::MakeNode`의 `saveload_playerlevel` 타일 경계에서 수정했습니다. 메인 메뉴의 세이브 미리보기에도 적용되는 경로입니다.

- `레벨 N: 시민`의 혼합 CP949/UTF-8 문자열 및 전체 UTF-8 문자열을 확인해, 표시용 문자열만 CP949로 무손실 변환합니다.
- 엄격한 UTF-8 유효성·CP949 표현 가능성 검사와 중복 변환 방지를 적용했습니다.
- 원본 `.fos`, `.nvse` 저장 파일과 원본 모드의 실제 기록은 변경하지 않습니다.
- 진단 메시지는 글자 수와 변환 상태만 기록하며, 세이브 제목 및 사용자 이름을 기록하지 않습니다.

의료 가방 UI 표시/효과 설명 관련 정적 수정이 적용되었습니다. 실제 변경 레코드와 수정 경로는 배포에 포함된 `build-report.json`의 `medical_source_changes` 및 `medical_change_paths`에서 확인할 수 있습니다. **의료 가방에 대한 실게임 검증은 아직 수행하지 않았습니다.**
