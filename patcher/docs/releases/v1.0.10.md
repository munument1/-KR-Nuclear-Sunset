## 세이브/불러오기 화면의 레벨 칭호 글자 깨짐 대응 (#27)

제보된 실제 Fallout New Vegas `.fos` 세이브의 레벨은 1이며, 칭호 `볼트 거주자`는 **정상적인 UTF-8 16바이트**로 저장돼 있었습니다. 따라서 원본 세이브 파일을 수정하지 않고 **게임 화면의 표시 단계**를 수정했습니다.

- 기존 tNVSE 71 네이티브 소스의 `FontEx::CreateText` 및 `FontEx::MakeString` 경계에서, 혼합된 CP949/UTF-8 UI 문구 중 **현재 세이브 목록에 존재하는 UTF-8 칭호와 정확히 일치하는 부분만** CP949로 무손실 변환하는 코드를 추가했습니다.
- 전체 UI 문구가 이미 정상 UTF-8인 경우, 저장된 칭호가 일치하지 않는 경우, CP949로 무손실 변환할 수 없는 경우에는 변경 없이 기존 경로로 처리합니다.
- 일반적인 CP949 텍스트의 불필요한 세이브 목록 검색을 줄이는 UTF-8 한글 후보 필터와 읽기 범위·목록 수 제한을 적용했습니다.
- 사용자 `.fos`, `.nvse`, 원본 게임 및 설치된 모드 파일은 읽기/수정하지 않으며, 패처는 기존처럼 Output만 생성합니다.
