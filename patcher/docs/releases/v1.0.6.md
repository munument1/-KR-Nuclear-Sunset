# Nuclear Sunset Korean Patcher v1.0.6

**정식 업데이트 — 퍽 선택창 글자 깨짐 수정 적용 / 인게임 확인 필요**

이슈 [#14](https://github.com/munument1/-KR-Nuclear-Sunset/issues/14)의 퍽 선택창 전용 한글 깨짐 제보에 대응하여, `NSKR UI Strings.esp`의 `sOr` 문자열을 이전 정상 버전(v1.0.2)의 UTF-8 인코딩으로 복원했습니다.

- v1.0.3에서 키 안내를 수정하면서 `sOr`가 CP949로 바뀐 내역을 공식 배포본의 실제 바이트로 확인했습니다.
- 이번 릴리스는 `sOr` **한 항목만 수정**하고, 키 안내용 `sPCControlsTextPrefix` 및 그 밖의 플러그인·번역 사전·DLL·INI·폰트·스크립트는 v1.0.5 그대로 유지합니다.
- 공식 v1.0.5 패처와 TranslationData ZIP에서 변경 파일/레코드/해시를 검증했고, 테스트 15개가 통과했습니다.
- 패처 실행 파일은 v1.0.5와 동일하므로, **프로그램 내부 버전 표시에는 v1.0.5가 남을 수 있습니다.** 이 릴리스의 식별 기준은 ZIP 파일 이름과 SHA256SUMS.txt입니다.

## 확인 필요

**실제 게임에서 퍽 선택창의 모든 글자 깨짐이 해결됐는지는 아직 확인하지 못했습니다.** 지금 적용한 `sOr`의 UTF-8 복원이 모든 퍽 요구 조건에 영향을 주는지 확정되지 않았고, 기존 키 안내 문구의 출력에 영향이 있는지도 실게임 검증이 필요합니다.

업데이트 후에는 패처를 다시 실행해 새 Output을 생성하고, 퍽 선택창의 요구 조건·설명 및 키 안내 문구가 정상 표시되는지 확인해 주세요. 문제가 남는다면 이슈 #14에 게임 화면과 사용한 UI 모드 정보를 남겨 주시면 후속 수정에 반영하겠습니다.
