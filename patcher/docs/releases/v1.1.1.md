# Nuclear Sunset Korean Patcher v1.1.1

## B42 Descriptions 한글 설명 전수 보완

현재 Nuclear Sunset `KR - Uranium Haze NVR High` 모드 구성에 맞춰 **B42 아이템 설명용 INI 118개, 2,992개 설명**을 기존 검수된 `NSKR_UI_Translations.json` 사전의 영문 원문과 대조해 한국어로 교체합니다. 원본 영어 및 표시 제어 문자를 보존하며, 검수된 번역이 없는 문구를 임의로 생성하지 않습니다.

- `B42 Descriptions Revised`: 2,061건. `NVDoctorBag` 의료 가방의 긴 아이템 설명 포함.
- B42 부가 설명 및 호환 모드 11종: 931건. `SPARE TTW Descriptions`, `DMT Descriptions`, `Stars TTW`, `New Vegas Bounties I LE - Gassy's Fixes` 등.
- 이중따옴표로 감싼 원문 88건은 양쪽 따옴표를 그대로 보존합니다.
- 오래된 `[OP] - B42 Descriptions`와 `New Vegas Bounties I LE` 본편의 하위 우선순위 INI는 상위 최신 파일을 덮지 않도록 의도적으로 제외합니다.
- 공급자별 원본 파일 SHA-256, 줄 번호, 키, 영문 원문이 정확히 일치할 때만 번역 Output을 만듭니다. 원본 업데이트로 해시가 달라지면 안전하게 건너뛰고 보고합니다.

## v1.1.0 수정 유지

세이브/불러오기 창 한글 레벨 칭호 수정과 `Aid Addon.esp` 의료 가방 동적 효과 설명 수정은 그대로 포함됩니다. tNVSE 네이티브 DLL, 게임 세이브, 원본 ESM/ESP, 패쳐 TranslationData의 나머지 번역은 v1.1.0과 동일합니다.

## 검증 및 알려진 미해결 문제

기존 번역 사전과 원문 대조, 변경되지 않은 줄과 서식 기호 보존, 전체 118개 INI의 반복 생성·SHA 동일성, 패쳐 단독 최종화 테스트를 통과했습니다. **이번 B42 설명 출력은 실제 게임에서 시각적으로 검증하지 않았습니다.**

GitHub 이슈 [#22](https://github.com/munument1/-KR-Nuclear-Sunset/issues/22)의 상단 알림 깨짐과 [#29](https://github.com/munument1/-KR-Nuclear-Sunset/issues/29)의 기타 `Glowing Fungus` 출력 경로는 B42 설명 수정으로 해결됐다고 간주하지 않으며 계속 추적합니다.

## 설치

전체 `NuclearSunset-Korean-Patcher-v1.1.1.zip`을 별도의 새 폴더에 풀고 실행 파일에서 새 `Output`을 생성해 MO2에 적용합니다. 기존 버전의 EXE·TranslationData·네이티브 DLL을 혼용하지 마세요. 게임 종료 후 설치하고 재시작해야 합니다.
