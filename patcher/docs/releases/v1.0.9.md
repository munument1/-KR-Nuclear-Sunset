# Nuclear Sunset Korean Patcher v1.0.9

v1.0.8을 기반으로 확인된 번역 출력과 인코딩 문제를 수정했습니다.

- #20: `SPARE.esp`의 탄피 이름 7건을 `[탄피] ...` 형식으로 통일했습니다. 영문 원문·레코드 ID·필드를 고정하고 기존 한국어 번역을 이전 값으로 보존하므로 1.0.8 적용본에도 재적용할 수 있습니다.
- #20: 스킬북/의학 학술지 아이템 **효과 설명**에서 깨지던 `영구 효과:`(Stewie Tweaks `[Book Effects] sPrefix`)의 인코딩을 다른 스킬명과 같은 CP949로 정규화했습니다. 표지 이미지나 책 본문 변경이 아닙니다.
- 그 외 v1.0.8의 기존 tNVSE DLL, 폰트 및 XEditLib 바이너리는 변경하지 않았습니다. 이번 업데이트의 새 코드가 적용되도록 패처 실행 파일은 새로 빌드합니다.

자동 테스트에서는 1.0.8 공식 배포 카탈로그 기준 7개 레코드만 변경됐는지와 스킬북 접두어의 안전한 재패치/다른 INI 보존을 확인했습니다. 정적 검증이 실게임 동일 세이브 결과를 확정하는 것은 아닙니다.

## 설치

**전체 패처 ZIP을 새 폴더에 해제하고, 새 Output을 생성한 후 기존 Output 대신 적용하세요.**
