## 중요 수정

**명확한 비표시 레코드 4,526건을 일반 번역 대상에서 제외**하고 후속 적용에서는 원문/기술 데이터가 변형되지 않도록 조치했다.

## 실행과 QA 안전장치

- `tools/translation_field_policy.py`: 비표시 판정의 중앙 원칙.
- `tools/run_gemini_nuclear_unattended.py`: 저장되지 않은 JSON 배치의 비표시 필드는 **API 호출 배열에서 제거**하고, 결과 JSON에서는 해당 원문을 변형 없이 보존한다. 원문 ID/키/순서는 불변. 기존에 저장된 결과는 덮어쓰지 않는다.
- `tools/check_gemini_json_results.py`: 신규/기존 결과를 모두 평가할 때 비표시 필드를 `SKIP_NON_DISPLAY`로 표시하며 **번역 후보 문자열을 비움**. 결과 CSV를 검수·적용할 때 이 상태를 번역하지 않도록 사용한다.
- API 프로젝트 키 및 기존 원본 파일은 불변. GitHub에는 검사/번역기 코드와 집계 보고서만 올린다.
- 아직 번역 출력 전체를 패쳐에 적용하거나 정식 릴리즈하지 않는다.
